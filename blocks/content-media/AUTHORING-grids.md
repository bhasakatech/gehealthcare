# Authoring multi-image grids — Logos page (and other brand-foundation pages)

Brand-foundation pages (e.g. **Logos**) show a section's example images in
**multi-column grids** (2-up / 3-up), like the live brand hub. Grids are produced
automatically — you don't build a grid block by hand.

## How the grid forms

- Each grid tile is **one Content Media block** with:
  - **Image** — the example image (pick from DAM)
  - **Text** — a short caption/label (bold title + optional line of copy)
  - **Layout** — **"Caption card (image + label, grids with siblings)"**
- Within a section (everything under one heading), all caption cards are gathered
  into one responsive grid. Columns auto-fill by width (≈2-up on medium, 3-up on
  wide) — you do **not** set a column count.
- A grid appears only when a section has **2+ caption cards**. A lone caption card
  stays full width. Headings, prose and Dos/Don'ts keep their place.
- **Dos/Don'ts example grids** (the ones with the red ✗ / green ✓ badges) are a
  **separate block** — the **Dos-Donts** block — not Content Media. They already
  grid on their own.

## Image source

All images come from the live brand hub. Upload to the DAM first, then pick them
in each block's **Image** field. Filenames below omit the host/path prefix:

`https://brand.gehealthcare.com/wp-content/uploads/2026/04/<name>`

Most are `…-scaled.jpg`. A few are plain `.png`/`.jpg` (noted). Alt text is empty
on the live site (decorative) — add descriptive alt if your standards require it.

## Quick recipe per tile

1. Insert a **Content Media** block under the correct heading.
2. Set **Layout** = *Caption card (image + label, grids with siblings)*.
3. Pick the **Image** from the DAM.
4. In **Text**, put the bold title (and the descriptive line where the live page has one).
5. Repeat for each tile in the section — matching cards auto-grid.

Dos/Don'ts example tiles use the **Dos-Donts** block instead (choose the ✓/✗ per
tile); they grid on their own.
